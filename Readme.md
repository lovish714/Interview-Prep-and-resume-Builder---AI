# 🤖 AI Interview Prep & Resume Builder

An AI-powered full-stack web application that helps users build professional resumes and prepare for interviews using Artificial Intelligence.

The platform provides personalized interview preparation, resume assistance, interview reports, and skill-gap analysis to help candidates improve their job readiness.

## 🚀 Features

- 🔐 User Registration & Login
- 📄 AI-powered Resume Builder
- 🤖 AI-generated Interview Questions
- 🎯 Personalized Interview Preparation
- 📊 Interview Performance Reports
- 🧠 Skill Gap Analysis
- 💡 AI-generated Feedback
- ☁️ Cloudinary File/Image Upload
- 🔒 JWT-based Authentication
- 📱 Responsive User Interface
